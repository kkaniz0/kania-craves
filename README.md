# Kania Craves

Personal food discovery — wherever you are, see what’s worth eating nearby from **your** wishlist, favorites, and visit history.

## Quick start

```bash
export PATH="$HOME/.local/node/bin:$PATH"
cd "KANIA CRAVES"
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

**Demo mode is on by default.** Hard-refresh the browser once so the new seed data loads (storage key bumped).

1. Allow location **or** pick **Senopati** / **Blok M**
2. See Top Pick / Wishlist Nearby
3. **Navigate** opens Google Maps with the restaurant’s real name + address

## Scripts

- `npm run dev` — development
- `npm run build` — production build
- `npm run start` — production server
